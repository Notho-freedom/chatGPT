# ChatGPT Interface

Interface and scripts for interacting with ChatGPT and OpenAI APIs.

## 🚀 Features

- 🤖 **ChatGPT integration** - Direct API integration
- 💬 **Conversation management** - Handle multi-turn conversations
- 🔧 **Utility scripts** - Helper functions for API calls
- 📝 **Prompt templates** - Reusable prompt templates

## 🛠️ Tech Stack

- **Language**: Python
- **API**: OpenAI API
- **Tools**: Requests, Python-dotenv

## 📁 Project Structure

`
chatGPT/
├── chatGPT.py         # Main ChatGPT interface
└── README.md
`

## 🚀 Installation

`ash
git clone https://github.com/Notho-freedom/chatGPT.git
cd chatGPT
pip install -r requirements.txt
`
